# 车联网 TSP 标准符合性矩阵

> 复盘日期：2026-11
> 范围：星途 TSP 参考实现（本仓库），不是第三方检测报告，也不构成法律/合规认证结论。
> 方法：以国家标准/行业标准官方公开页面核对**版本、状态、替代关系**；条款级符合性需购买授权标准全文并由具备资质的检测机构判定。本文不引用未公开的条款原文。

## 1. 先纠正一个版本事实

仓库早期文档和代码把协议写成 **JT/T 808-2013**。核对官方标准页面后确认：

- 现行版本是 **JT/T 808-2019**，2019-03-15 发布、2019-07-01 实施；
- 它**全部代替 JT/T 808-2011**；
- 官方公开页面未列出“JT/T 808-2013”这一版本；因此把 2013 作为正式版本号用于投标、备案或符合性声明是不严谨的。

参考：[交通运输部标准页面 JT/T 808-2019](https://jtst.mot.gov.cn/hb/search/stdHBDetailed?id=2eabe27a635213c9af12f3aeadd2c906)

本次复盘已把仓库中的协议标签统一改为 **JT/T 808-2019**，并在代码注释中明确“这是子集，不是完整符合性实现”。

## 4. JT/T 808-2019 实现矩阵

### 4.1 已实现

| 消息/能力 | 状态 | 说明 |
| --- | --- | --- |
| 12 字节消息头 | 部分 | 消息 ID、消息体属性、BCD 终端号、流水号、包体 |
| 0x0100 终端注册 | 部分 | 解析厂商/型号，返回 0x8100 + 鉴权码；未完整解析省域/市县域/终端 ID/车牌颜色 |
| 0x0102 终端鉴权 | 是 | 校验终端号 + 鉴权码；本次修复后注册不再自动置为已认证 |
| 0x0002 心跳 | 是 | 鉴权后刷新在线状态/最近心跳 |
| 0x0200 位置汇报 | 部分 | 报警、状态、经纬度、高度、速度、方向、BCD 时间、0x01 里程、0x31 卫星数 |
| 0x8001 通用应答 | 是 | 请求流水号 + 结果 |
| 0x8100 注册应答 | 是 | 请求流水号 + 结果 + 鉴权码 |
| 7E 转义 / XOR / BCD | 是 | 有单元测试；拒绝非法转义/校验失败 |
| 分包/加密 | 部分 | 分包重组已实现；加密仍拒绝 |
| 0x0704 批量定位 | 部分 | 解析/入库已实现，未做批量限流/分组统计 |
| 0x0201/0x0202 位置查询/追踪 | **否** | 未实现 |
| 0x8103/0x8104/0x8105/0x8106/0x8107 参数/属性 | 部分 | body 编码器 + 下行 API + `0x0001` 应答状态查询已实现；参数持久化/重试未完成 |
| 0x8201/0x8202/0x8203/0x8204 | 部分 | 0x8201 已回 0x0201 当前位置；0x8202/0x8203/0x8204 已 ACK，跟踪状态机未实现 |
| 0x8300/0x8301/0x8302/0x8303/0x8304 | **否** | 文本、事件、菜单、服务等未实现 |
| 0x8400/0x8401/0x8402 电话/短信/电话簿 | **否** | 未实现 |
| 0x8500 车辆控制 | 部分 | body 编码器 + `/vehicle-control` action profile（lock/unlock/start/stop/find/trunk/ac）+ 原始 flag；不同 T-Box 需替换 profile |
| 0x8600–0x8608 区域/路线 | **否** | 未实现 |
| 0x8700/0x8701/0x8702 行驶记录/电子运单 | **否** | 未实现 |
| 0x8800–0x8805 多媒体/录音 | **否** | 未实现 |
| 0x8900/0x8A00/0x8F00 等扩展 | **否** | 未实现 |

> 结论：**不能声明“符合 JT/T 808-2019”**。准确表述应为“实现 JT/T 808-2019 的注册/鉴权/心跳/0x0200 位置子集，用于演示与二次开发”。

### 4.2 本次已修复的 808 问题

1. **注册即认证**：原实现收到 0x0100 后直接 `authenticated=true`，绕过 0x0102。已改为注册后仍等待鉴权，心跳也要求已鉴权。
2. **鉴权码可预测**：原为 `XT` + 终端号后 6 位，易猜测。已改为 12 位随机字母数字后缀。
3. **版本标签错误**：统一改为 JT/T 808-2019，并标注“子集”。
4. **协议标签写入数据库**：终端/种子数据的 `protocol` 字段统一为 JT/T 808-2019。

仍未修复：鉴权码明文存储、加密、0x0100 失败重试语义、流水号回绕、终端多连接会话冲突；分包重组与 0x0704 已补。

## 7. 标准符合性结论

| 结论 | 判断 |
| --- | --- |
| 是否可直接用于道路运输车辆监管备案 | **否** |
| 是否可通过 JT/T 808-2019 符合性检测 | **否**（仅子集） |
| 是否可通过 JT/T 809-2019 平台交换检测 | **否**（未实现） |
| 是否满足 GB/T 32960-2025 | **否**（未实现） |
| 是否满足等保三级 | **否**（未定级/未测评） |
| 是否适合作为演示、POC、二次开发基线 | **是**，但必须明确“非合规成品” |

## 8. 建议的符合性建设顺序

1. **P0**：关闭演示默认值；补齐 808 注册/鉴权/心跳/0x0200 的 2019 字段与错误语义；建立终端接入安全基线。
2. **P1**：0x0704 批量定位、0x8103/0x8104/0x8105/0x8106/0x8107 参数管理、0x8201/0x8202/0x8203、0x8300/0x8500 下行与应答；分包/加密。
3. **P1**：JT/T 809 平台交换适配器 + 监管平台联调；GB/T 32960.3-2025 适配器。
4. **P2**：JT/T 1078 视频/主动安全；GB/T 19056 记录仪；地方标准（按运营地）。
5. **全程**：等保/密码应用/汽车数据安全治理与检测报告。
