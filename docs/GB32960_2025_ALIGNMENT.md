# GB/T 32960.3-2025 对齐台账

> 依据公开的 2025 版文本与官方标准信息页整理。  
> 本文只记录代码事实，不构成标准符合性声明或认证结论。

## 1. 版本

- 现行：GB/T 32960.3-2025
- 代替：GB/T 32960.3-2016
- 发布：2025-04-25
- 实施：2025-11-01
- 官方页面：<https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=868AD22C1502F9494A36019BB7B89737>

## 2. 2025 主要技术变化

公开文本列出的变化：

1. 平台间、车载终端与平台间通信安全要求。
2. 动力蓄电池最小并联单元定义及电压/温度数据。
3. 燃料电池电堆、超级电容器、超级电容器极值数据。
4. 行驶完成下高压/充电完成下高压后 1 小时数据监控。
5. 热事件报警期间数据上传要求。
6. 协议版本号区分。
7. 应答错误标志定义。
8. BMS 数量、对应电池包个数、电池包编码；删除“可充电储能子系统”概念。
9. 签名信息、激活信息、激活结果应答。
10. 最小并联单元电压、温度、燃料电池电堆、超级电容、超级电容极值的信息类型标志。
11. 删除动力蓄电池极值数据。
12. 整车数据中车速、总电压、总电流范围及绝缘电阻定义调整。
13. 删除电机控制器输入电压/直流母线电流。
14. 燃料电池改为“燃料电池发动机及车载氢系统数据”，增加剩余氢量、高压 DC/DC 温度。
15. 删除发动机状态平均百公里燃料消耗率。
16. 车辆位置数据要求调整。
17. 增加热事件报警等级、报警标识位、N5 通用报警等级列表。
18. 挡位状态无效/有效识别。
19. 车辆静态信息列表调整。

## 5. 约束

- 不把 2016 字段直接当 2025 字段使用。
- 不在缺少分组模式/填充/IV 的情况下实现“AES 解密”。
- 不把“帧头能识别加密方式”说成“支持加密通信”。
- 不声明 GB/T 32960.3-2025 符合性或通过一致性测试。

## 7. 2025 信息类型标志（表 9，已核对）

| 编号 | 含义 |
| --- | --- |
| 0x01 | 整车数据 |
| 0x02 | 驱动电机数据 |
| 0x03 | 燃料电池发动机及车载氢系统数据 |
| 0x04 | 发动机数据 |
| 0x05 | 车辆位置数据 |
| 0x06 | 报警数据 |
| 0x07 | 动力蓄电池最小并联单元电压数据 |
| 0x08 | 动力蓄电池温度数据 |
| 0x09–0x2F | 平台自定义 |
| 0x30 | 燃料电池电堆数据 |
| 0x31 | 超级电容器数据 |
| 0x32 | 超级电容器极值数据 |
| 0x33–0x7F | 预留 |
| 0x80–0xFE | 自定义 |
| 0xFF | 签名数据开始标识 |

注意：2016 的报警为 0x07、电压 0x08、温度 0x09；2025 整体前移，不能混用。
