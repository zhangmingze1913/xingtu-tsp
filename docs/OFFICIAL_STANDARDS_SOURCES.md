## 2. 808 官方全文核对的关键结论

通过官方全文阅读器（`/kfs/file/read/...` → `/kfs/file/readPage`）获取并 OCR 第 25–40 页，确认：

### 2.1 0x8301–0x8304 在 2019 中不存在

- 2019 目录中 0x8300 文本信息下发之后直接是 0x8400 电话回拨。
- 0x8301 事件设置、0x8302 提问下发、0x8303 信息点播菜单、0x8304 信息服务属于 **2011 版**。
- 当前代码中的 0x8301–0x8304 编解码只能标为“2011 遗留/候选”，不能作为 2019 能力。

### 2.2 0x8400 电话回拨

官方表 39：

| 字段 | 类型 | 要求 |
| --- | --- | --- |
| 标志 | BYTE | 0：普通通话；1：监听 |
| 电话号码 | STRING | 最长 20 字节 |

此前代码把标志写成 0/1=呼入/呼出、号码上限 32，已修正为官方语义与 20 字节。

### 2.3 0x8401 设置电话本

官方表 40/41：

| 字段 | 类型 | 要求 |
| --- | --- | --- |
| 设置类型 | BYTE | 0 删除全部；1 更新；2 追加；3 修改 |
| 联系人总数 | BYTE | 联系人项数量 |
| 标志 | BYTE | 1 呼入；2 呼出；3 呼入/呼出 |
| 号码长度 | BYTE | n |
| 电话号码 | STRING | GBK |
| 联系人长度 | BYTE | 联系人姓名长度 |
| 联系人 | STRING | GBK |

已按此实现 `encode_phone_book`/`decode_phone_book`。

### 2.4 0x8600 设置圆形区域

## 3. 对当前代码的影响

1. **0x8301–0x8304 不能计入 2019 完成度**，只能保留为 2011 兼容/候选。
2. **0x8400 已按官方语义修正**：标志 0 普通通话、1 监听；号码 ≤20 字节。
3. **0x8401/0x8600/0x8601 已按官方表实现编解码**，但尚未接入命令 API（目前只有 codec/单测）。
4. **GB/T 32960.3 必须按 2025 版重评**：当前代码未锁定版本，不能声明 2025 符合性。
5. **DB31/T 1409.1-2023 已废止**：旧路线图把它当现行示例是错误的，项目启动前必须向上海市市场监管局确认现行替代标准。
6. **JT/T 808 第1号修改单未实现**：需把修改单纳入版本台账和字段差异。
7. **JT/T 809 修改单未实现**：驾驶员身份信息新增身份证 UID、身份证号、人脸匹配度字段。
