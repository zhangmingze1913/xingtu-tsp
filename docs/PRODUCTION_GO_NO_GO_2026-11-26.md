# 星途 TSP 生产 Go/No-Go 评估（2026-11-26）

> 结论：**No-Go for production**。
> 可以进入受控试点/POC 验收，但不能直接用于生产远程车控、监管备案或对外承诺标准合规。

## 2.1 模拟测试的边界

已新增真实 TCP 模拟终端（注册/鉴权/心跳/位置/重复/重连），以及 809/1078/32960 模拟。

模拟可以降低“协议路径未验证”的风险，但**不能关闭真实终端/平台/视频和官方检测项**：

- 无 GPS/射频/车辆总线
- 无真实摄像头/编码器
- 无运营商弱网
- 无真实监管平台
- 无官方测试集

详见 [SIMULATION_TESTS.md](SIMULATION_TESTS.md)。

## 5. 安全与合规

已有：

```text

PII 加密/批量 hydration、PII 删除接口
JT808 TLS/mTLS、Redis TLS 配置
导出 AES-GCM、单次下载令牌
审计日志
```

缺少：

```text

KMS/HSM 实际托管与轮换演练
日志脱敏与留存合规验证
```

## 7. 可以做什么

### 可以做

```text
内部演示/POC
受控试点（非生产远控）
开发/测试环境
信创关系型数据库适配验证
运维手册/架构评审
```

### 不能做

```text
生产远程车控
监管备案
对外承诺 JT/T 808/809/1078/GB/T 32960 合规
无人值守视频/告警闭环
替代第三方检测
```

## 9. 建议路径

```text
阶段 A：受控试点
  真实终端 1–2 台、单组织、非远控/或双人复核
  观察 2–4 周，修协议/告警/运维问题

阶段 B：小规模生产
  10–50 台、主备 DB、监控/备份、只读+有限远控
  完成安全整改

阶段 C：规模生产
  多副本/多 AZ、真实容量、标准检测、KGSI/地方接口
```

## 10. 结论

> **当前系统业务闭环和技术底座足以做受控试点，但不满足生产环境要求。阻断项主要是真实终端/平台/视频联调、官方标准一致性、KGIS、生产级 HA/灾备、安全测评和生产规模验证；这些不能由代码占位或本地 mock 替代。**
