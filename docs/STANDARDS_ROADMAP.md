# TSP 标准实现矩阵与落地路线

> 复审日期：2026-11-18  
> 范围：星途 TSP 参考实现（本仓库）。本文不是第三方检测报告，不构成标准符合性/认证结论。  
> 判定口径：**只有编解码、网关/业务处理、错误语义和测试都具备，才标“完成”**；有字段/骨架但未联调，一律标“部分”；只有常量，标“未实现”。

## 1. 结论

| 标准 | 当前状态 | 结论 |
| --- | --- | --- |
| JT/T 808-2019 | **核心子集 + Phase 1 增量** | 注册/鉴权/心跳/位置/批量/查询/参数/文本/临时跟踪等可用；2019 完整字段宽度、告警确认、加密、真实终端互通未完成 |
| JT/T 809-2019 | **骨架** | 传输帧 + 登录体子集；无消息目录、握手、业务体、加密/压缩 |
| GB/T 32960.3-2025 | **骨架 + 子集** | 传输头 + 0x01 前 20 字节 + 0x02 登录体；电机/电池/告警/登出/心跳/一致性未实现 |

| JT/T 796-2019 / GB/T 35658-2017 | **部分** | 有监控/轨迹/围栏/告警/统计；缺监管接口、平台间交换、性能/可靠性证据 |

| GB/T 32960.1/.2/.4-2025 | **未实现** | 总则/终端/一致性测试未落地 |
| GB/T 22239-2019 等保 | **部分** | 有认证/RBAC/审计/TLS；无定级备案、完整审计留存、入侵防范 |

## 6. 完整实现路径

### Phase 0：标准基线与一致性测试台（2 周）

- 获取现行标准全文/官方接口文档，建立版本台账。
- 建立 `standards/catalog`：消息 ID、方向、必选/可选、字段、错误码、版本。
- 建立帧样本库：正常/边界/非法/分包/重传/加密。
- 测试台：单元 roundtrip/fuzz；集成模拟终端↔平台；回归真实抓包。
- 产出：`conformance-matrix.csv`、测试报告模板、CI job。

**DoD**：已声明消息都有正/反用例；CI 可重复执行；不用“常量存在”代表实现。

### Phase 1：JT/T 808-2019 核心 + 生产必需（4–6 周）

**已完成增量**：0x0100 双布局、0x0107 候选字段、0x0104/0x0107 落库、0x8300、0x8202/0x8204 状态、0x0200 语义、0x0704 去重/上限、跨节点单会话。

**剩余**：

1. 用授权全文核对 0x0100/0x0107 的 2019 字段宽度。
2. 0x0200 项目必选附加项完整语义。
3. 0x0704 分片/乱序/超时/限流；并发幂等已加 `telemetry_claims`。
4. 0x8203 告警确认（需标准字段/样本）。
5. 0x8103/0x8106 参数持久化、版本、差异、重试。
6. 流水号回绕、全局限流、真实终端抓包。
7. 加密：TLS/mTLS 已具备；协议层加密单独实现并做负向测试。

**DoD**：项目必选消息 100% 覆盖；异常/重传/并发有测试；至少 2 家终端/平台互通。

### Phase 2：JT/T 809-2019 平台交换（4–6 周）

1. 消息目录与业务体（车辆定位/报警/平台应答/登录/注销/心跳）。
2. 上下级平台握手、鉴权、平台编码映射。
3. 加密/压缩、CRC/长度/流水号校验。
4. 断线重连、重发、去重、顺序保证。
5. 省级/部级监管平台联调。
6. 对接凭据、白名单、审计。

**DoD**：809 必选消息互通；断网/重连/重复包测试通过；监管平台联调报告。

### Phase 3：GB/T 32960.3-2025（4–6 周）

1. 0x01 全数据单元：整车/驱动电机/燃料电池/发动机/极值/报警。
2. 0x02 登录、0x07 登出、0x04 心跳、平台应答。
3. 加密、VIN/ICCID 校验、时间/序列。
4. 2025 版本与地方监管差异适配。
5. GB/T 32960.4 一致性预演。

**DoD**：0x01–0x04 必选字段全覆盖；与 2 家新能源终端/平台互通；数据对账。

### Phase 4：视频/记录仪/平台要求（6–8 周，按项目取舍）

- JT/T 1078/1077：视频终端注册、预览、回放、对讲、主动安全。
- GB/T 19056：记录仪数据读取/取证/校验。
- JT/T 796 / GB/T 35658：平台功能/性能/可靠性条款证据。
- 监管平台/联网联控接口。

**DoD**：项目范围条款逐项有实现/测试/证据。

### Phase 5：安全合规与地方标准（4 周，可并行）

- 等保 2.0 定级/备案/测评整改。
- 汽车数据/个人信息：告知同意、最小必要、匿名化、留存/删除/导出。
- 密码应用：国密/TLS 证书/密钥生命周期。
- 地方标准：独立 adapter，不污染 808 核心。
- 第三方检测/认证。

**DoD**：差距项关闭；外部测评/联调报告；版本台账可追溯。
